# Vue Composables

## Usage

```ts
import { useAccount, useConnect } from '@ivem/kit-vue'
```

## Parameters

Composables read config from `IvemPlugin` context.
Mutation/composable state is managed by TanStack Query.

## Return Type

State values are exposed as Vue `Ref` wrappers when applicable.
