# vite-react playground

React + Vite playground for `@ivem/kit-react`.

## Run

```bash
pnpm dev:playground:react
```

Open http://localhost:3000.

## Coverage

- Connect and disconnect iWallet Pro.
- Read account and chain state.
- Sign messages.
- Send IOST transfers.
- Write and call contracts.
- Inspect wallet events and public node info.
