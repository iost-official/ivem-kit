# useChainId

## Usage

```tsx
import { useChainId } from '@ivem/kit-react'

const chainId = useChainId()
```

## Parameters

- None

## Return Type

- `string`

## Examples

```tsx
function CurrentChain() {
  const chainId = useChainId()
  return <span>{chainId}</span>
}
```
