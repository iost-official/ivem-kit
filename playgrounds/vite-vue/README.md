# vite-vue playground

Vue 3 + Vite playground for `@ivem/kit-vue`.

## Run

```bash
pnpm dev:playground:vue
```

Open http://localhost:3001.

## Coverage

- Connect and disconnect iWallet Pro.
- Read account and chain state.
- Sign messages.
- Send IOST transfers.
- Write and call contracts.
- Inspect wallet events and public node info.
